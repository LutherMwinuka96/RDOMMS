RDO|MMS User Manual

This guide covers the most common actions in the system: signing in, managing your profile, working with projects, reports, finances, notifications, and settings.

Download PDF Manual Open Dashboard Video Tutorials

Getting Started

  • Sign in using your registered email and password.
  • Use the top-right user menu to access profile, password, settings, help, and logout.
  • Sidebar modules open the main workflow pages.

Profile Updates

  • Open My Profile from the user dropdown.
  • Use Change Photo to upload a new profile picture.
  • Use Edit and Save Changes to update your details.

Reports and Planning

  • Generate reports from the Reports section.
  • Track project status from Projects and Planning pages.
  • Use the date range selector on the dashboard for filtering.

Support

  • Open Help & Support from the user dropdown.
  • Download the full PDF manual for offline reading.
  • Check system notifications for updates and alerts.
