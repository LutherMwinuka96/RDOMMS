Email / SMTP Settings

Configure SMTP so forgot-password and system emails reach real inboxes (Gmail, Outlook, etc.)

SMTP is required on WAMP. PHP mail() does not work locally without a mail server. Use Gmail SMTP with an App Password to send real emails.

Gmail Setup Steps

  1. Open Google Account → Security → turn on 2-Step Verification
  2. Create an App Password for "Mail" / "Other (RDO|MMS)"
  3. Paste the 16-character app password in the field above (not your normal Gmail password, no spaces)
  4. If you see error 535 BadCredentials, re-enter a fresh App Password and click Save
  5. Set App Base URL to http://localhost/RDOMMS
  6. Save, then click Send Test Email to your own address
  7. After test succeeds, use Forgot Password — email will arrive in inbox

Alternative: copy config/mail.local.php.example to config/mail.local.php and fill credentials there.
